04 / notes

Some notes:

Sorry Firefox/Safari users, interpolate-size is still in beta. Sorry :(
001 Software should be simple

A lot of software is built with and without the user in mind. Ads and data collection comes standard nowadays which makes the experience feel less like a tool and more as you're the product. If a business needs to make money, that's fine, but it shouldn't come at the cost of the user.

002 Windows is annoying

I know Windows is slow, bloated, filled with tracking, but I do still use it. Most applications I use are either built purely for Windows or an alternative isn't sufficient on other platforms. I have tried both Linux and macOS, but I find that it's either too open to customization or has to steep of a learning curve to work with.

003 I'm not a designer

While I do like to make designs and want to make everything as good as possible, I'm not a designer. For this website, I've used a custom Discord skin as a design guide as I love the simplicity of it. If you've ever seen my Discord app show up on a screenshare, you'll instantly recognize the idea of the boxed elements I've used.
